# Personal Diary App

# About

Personal Diary App is a beginner-friendly Python project that allows users to write, view, and search their personal diary entries.

It uses Python file handling to save diary entries permanently in a text file.

Features

- Password-based login.
- Add new diary entries.
- View all diary entries.
- Search entries by title.
- Delete all diary entries.
- Automatically save entries in a text file.
- Display date and time for each entry.

Technologies Used

- Python
- File Handling
- Functions
- Loops and Conditional Statements
- Datetime Module

Requirements

- Python 3.x
- No external libraries required.

How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Run the following command:

python "Personal Diary.py"

4. Enter the password when prompted.

Default Password: "1234"

Project Structure

Personal-Diary/
│
├── Personal Diary.py
├── diary.txt
└── README.md

Note: The "diary.txt" file is automatically created when the first diary entry is saved.

Learning Objectives

This project helps beginners understand:

- Python functions.
- File handling.
- If-else conditions.
- While loops.
- String operations.
- Working with date and time.

Future Improvements

- Change password option.
- Delete individual diary entries.
- Edit existing entries.
- Password encryption.
- Graphical user interface.

Security Note

This is a beginner learning project. The default password is stored directly in the source code, and diary entries are saved as plain text. Do not store sensitive personal information in this version.
